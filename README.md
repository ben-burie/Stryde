# Stryde – AI Powered Running Coach Web Application

**Stryde** is an AI-powered web application designed to act as a personalized running coach. It leverages your personal running data to generate training guidance, plans, and insights.

## Demo

[Watch the demo video](https://www.youtube.com/watch?v=2jHlQ-ps44Q)


## Features

* **Coaching Chatbot:**
  Provides tailored, conversational responses to your questions using your personal running data as contextual input.
  
![chat](https://github.com/user-attachments/assets/8737537c-cd92-4cf0-ba00-da9a66ec4a3b)


* **30-Day Training Plan Generator:**
  Automatically generates a personalized 30-day training plan based on your historical running data.
  
![plan](https://github.com/user-attachments/assets/61639881-92c8-494d-bae1-071038e8591b)

* **Custom Data Upload:**
  Upload your own data downloaded from Strava to our platform to view fitness metrics and get personalized responses.

![dataupload](https://github.com/user-attachments/assets/7d539991-86e6-461b-b855-05c01bbc675f)
